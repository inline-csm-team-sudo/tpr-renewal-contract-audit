# Project instructions

For every request involving TPR renewals, Renewal DB, Build Queue, `TPR Update Queue`,
contract or email review, Share Plan review, or special-plan approval, use the project skill:

`$tpr-renewal-contract-audit`

The skill is located at:

`.agents/skills/tpr-renewal-contract-audit/SKILL.md`

Read its required reference completely before taking action. Treat that reference as the
authoritative rule set when older project specifications, historical Queue notes, or scripts
conflict. Never write to the formal TPR unless the user separately gives explicit authorization.
